# Домашняя контрольная работа — вариант №25

Инструмент командной строки для преобразования учебного конфигурационного
языка в JSON. Реализация использует Python 3.10 и стандартную библиотеку.

## Возможности

- однострочные комментарии `NB.`;
- числа по шаблону `[+-]?\d+\.?\d*[eE][+-]?\d+`;
- словари `@{ имя = значение; ... }` с произвольной вложенностью;
- глобальные константы `global имя = значение;`;
- ссылки на константы `#(имя)`;
- ссылки на константы, объявленные позже;
- диагностика синтаксических ошибок с номером строки и столбца;
- обнаружение повторных имён, неизвестных ссылок и циклических зависимостей.

Итоговый JSON — объект, ключами которого являются имена глобальных
констант. Значения констант могут быть числами или словарями.

## Структура

- `src/configlang/lexer.py` — лексический анализатор;
- `src/configlang/parser.py` — синтаксический анализатор;
- `src/configlang/resolver.py` — вычисление констант и ссылок;
- `src/configlang/cli.py` — интерфейс командной строки;
- `tests/` — автоматические тесты;
- `examples/` — три конфигурации из разных предметных областей.

## Установка

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Linux/macOS:

```bash
. .venv/bin/activate
python -m pip install -r requirements.txt
```

## Запуск

```bash
python -m src.configlang.cli examples/web_server.conf
```

JSON выводится в стандартный вывод. Ошибки направляются в стандартный поток
ошибок, программа завершается с кодом `2`.

Windows:

```powershell
run.bat examples/web_server.conf
```

Linux/macOS:

```bash
./run.sh examples/web_server.conf
```

## Синтаксис

```text
NB. комментарий
global имя = значение;

значение:
    число
    @{ имя = значение; ... }
    #(имя)
```

Каждое число обязано соответствовать заданному формату с экспонентой:
`10e0`, `-2.5E+1`. Запись `10` без экспоненты не является допустимым числом.

Объявления `global` образуют итоговый JSON-объект. Ссылки разрешаются
после разбора всех объявлений, поэтому допустимы ссылки на константы,
объявленные ниже по файлу. Циклические ссылки запрещены.

## Примеры

В каталоге `examples/` находятся:
- `web_server.conf` — конфигурация веб-сервера;
- `monitoring.conf` — конфигурация мониторинга;
- `warehouse.conf` — конфигурация склада.
